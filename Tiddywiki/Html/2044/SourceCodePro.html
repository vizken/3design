Source Code Pro

Source Code Pro 是一款專為程式碼編輯設計的等寬字體。它具有清晰的字形和一致的字元寬度， 提高了程式碼的可讀性和易讀性。

字體特色

等寬字體： 所有字元的寬度一致，方便程式碼對齊。
清晰字形： 易於區分相似字元，如 "l" 和 "1"、"0" 和 "O"。
專為程式碼設計： 優化了括號、引號等程式碼常用符號的顯示。
多種字重： 提供多種字重，方便在程式碼中區分不同元素。
屏幕優化： 在各種螢幕尺寸和解析度下都能清晰顯示。
